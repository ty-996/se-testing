# se-testing
# 实验四：单元测试与TDD
## 实验目标
掌握JUnit/supertest单元测试编写、Mock对象使用、TDD开发流程。
## 实验要求
1. 使用TDD方式开发一个计算器模块（先写测试再写实现）
2. 编写≥15个单元测试用例，覆盖正常/边界/异常情况
3. 使用Mock框架模拟外部依赖（数据库/网络请求）
4. 配置CI/CD流程（GitHub Actions自动运行测试）
5. 生成测试覆盖率报告（目标≥80%）
## 评分标准
| 项目 | 分值 |
|------|------|
| TDD流程 | 20% |
| 测试覆盖率 | 25% |
| Mock使用 | 20% |
| CI配置 | 20% |
| 报告 | 15% |
